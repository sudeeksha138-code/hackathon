System Architecture

How the Detection System Works

An end-to-end 5-step detection pipeline bridging front-end parameter collection with backend machine learning inference.

01

Feature Input

The user inputs 9 observable account parameters into the client-side form without entering any passwords or tokens.

02

REST API Dispatch

Vanilla JavaScript sends a POST request with the sanitized JSON payload to the Python Flask backend over HTTP/REST.

03

Backend Validation

Flask receives the request, enforces boundary and type constraints, and packages the 9-dimensional feature vector.

04

Random Forest ML

The pre-trained Scikit-learn Random Forest model generates class probabilities via 150 decision trees.

05

Explainable Dashboard

Risk percentage, verdict badge, and heuristic factor breakdowns are dynamically displayed to the user.

Project Overview

About the Project

Engineered as a 12-hour hackathon prototype demonstrating accessible machine learning applications in cybersecurity.

🎯

Project Objective

To construct a functional, transparent, and educational platform for evaluating social media account legitimacy without invasive credential requirements. Built specifically for college engineering hackathons.

🌲

Why Random Forest?

Random Forest excels with tabular metadata by handling non-linear feature interactions (e.g. high following with zero posts), resisting overfitting through bagging, and yielding transparent probability scores.

📊

Dataset & Methodology

The current pipeline includes a statistically grounded synthetic demonstration dataset (3,000 samples) mirroring published bot research. The architecture is modular and supports plugging in real-world Kaggle/MIB datasets via automated column mapping.

⚠️

Known Limitations

As a lightweight educational prototype, the system does not analyze natural language post semantics, computer vision avatars, or network graph topologies. Modern high-tier state-sponsored bots may mimic legitimate metrics.
